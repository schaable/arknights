# Generated collection covers

Four custom covers made with the built-in `image_gen.imagegen` tool on 2026-10-18 and activated in the VN reader on 2026-10-19. They use the event banners already stored in this repository and official game covers as visual references. No Timo reader images were used as inputs.

| Collection | Cover | Reference style |
| --- | --- | --- |
| Delicious on Terra | [act36side.png](act36side.png) | Side story archive card |
| A Flurry to the Flame | [act24side.png](act24side.png) | Side story archive card |
| It's Been A While | [act13mini.png](act13mini.png) | Vignette dossier |
| Ceobe's Fungimist | [rogue_0.png](rogue_0.png) | Integrated Strategies illustration |

These are the active covers for their collections, mapped in `vn/tools/cover-assets.json` and the generated catalog. The original reference banners remain preserved alongside this directory. Each PNG retains its generated resolution and transparent background.

The three event/vignette covers were revised on 2026-10-19 to use the official covers' white three-section recording reels and remove loose filmstrips and adhesive tape. Ceobe's Fungimist retains its original generated artwork. Edit prompts record the prior image's Git revision and checksum.

The images are AI-generated compositions, not unmodified official artwork. Generation can reinterpret character details. Arknights artwork and characters belong to Hypergryph and their respective rights holders.

Exact prompts and input references are recorded in [prompts.json](prompts.json). Source references, dimensions and checksums are recorded in [sources.json](sources.json). The original banner provenance remains in [../sources.json](../sources.json).
